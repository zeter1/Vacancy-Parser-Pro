# Документация Vacancy Parser Pro

[Корневой README](../README.md) владеет обзором проекта: назначение, установка и запуск, источники вакансий, фильтры зарплаты, карта основных файлов, диагностические сессии и команды проверки.

- [AGENTS.md](../AGENTS.md) — контракты адаптеров, потоков, конфиденциальности и сохранения данных.
- [SUPPORT.md](../SUPPORT.md) — данные для сообщения о проблеме источника.
- [SECURITY.md](../SECURITY.md) — сообщения об уязвимостях.
- [CHANGELOG.md](../CHANGELOG.md) — принятые изменения.

Сборкой Windows владеют `build_exe.bat` и `tools/build_windows.ps1`. Offline-тесты не подтверждают текущую доступность внешних сайтов; после изменения адаптера отдельно проверяйте реальный поисковый запрос и диагностику выбранного источника по AGENTS.md.
