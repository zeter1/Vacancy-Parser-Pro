# Поддержка и сообщения об ошибках

Для проблем Vacancy Parser Pro используйте GitHub Issue Form и приложите только безопасные диагностические данные.

Особенно полезны:

- версия/ревизия программы и версия Windows;
- источник вакансий, на котором проявилась проблема;
- профессия/ключевые слова, город, зарплата, опыт, формат работы и период публикации;
- точные шаги воспроизведения;
- ожидаемый и фактический результат;
- безопасная сводка соответствующей сессии из `Логи проблем/`.

## Если перестал работать один источник

Ошибка одного сайта не должна автоматически означать ошибку всего приложения. Укажите конкретный источник и проверьте диагностическую сессию: полезны HTTP status, категория ошибки и этап парсинга, но не секретные значения.

## Приватность

Не публикуйте OAuth-токены, cookie, ключи, персональные данные из вакансий сверх необходимого и другие секреты. Если лог содержит чувствительные URL или параметры, отредактируйте их перед публикацией.

Потенциальные уязвимости сообщайте по правилам из [`SECURITY.md`](SECURITY.md).
